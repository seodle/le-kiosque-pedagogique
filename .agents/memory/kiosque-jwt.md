## JWT Payload Union

```ts
type TokenPayload =
  | { type: "staff"; userId: number; role: string; email: string }
  | { type: "teacher"; ticketId: number }
```

Staff tokens expire in 8h, teacher tokens in 30d. Stored in `localStorage` as `kiosque_token`.

## Lib Rebuild Rule

After any change to `lib/db/src/schema/` (adding tables, columns), run:
```
pnpm run typecheck:libs
```
before running `pnpm --filter @workspace/api-server run typecheck`. Otherwise the api-server sees stale `.d.ts` declarations and reports false "module has no exported member" errors.

**Why:** `lib/db` is a composite TypeScript project. Its declaration files (`.d.ts`) must be regenerated by `tsc --build` before downstream packages can see new exports.
